# 使用评估

## 效率测试设计

### 任务 1：在论文中查找特定结论
**手动方式**：
1. 打开论文 PDF 或笔记
2. 搜索关键词（Ctrl+F）
3. 阅读搜索结果
4. 验证结论上下文
5. 预计耗时：每篇论文 5-15 分钟

**LabTrail 方式**：
1. 打开检索页面
2. 输入自然语言问题
3. 查看带来源引用的排序结果
4. 点击查看原始文档
5. 预计耗时：30 秒 - 2 分钟

### 任务 2：对比算法性能
**手动方式**：
1. 打开实验 CSV 文件
2. 按方法和数据集过滤
3. 手动计算统计数据
4. 在 Excel/Python 中创建对比图表
5. 预计耗时：30-60 分钟

**LabTrail 方式**：
1. 打开实验分析页面
2. 查看预计算的对比结果
3. 交互式图表自动更新
4. 按需导出
5. 预计耗时：1-2 分钟

### 任务 3：撰写科研周报
**手动方式**：
1. 回顾本周所有笔记
2. 总结实验结果
3. 列出结论和决策
4. 格式化报告
5. 预计耗时：1-2 小时

**LabTrail 方式**：
1. 打开周报页面
2. 点击"生成周报"
3. 审阅并导出 Markdown
4. 预计耗时：1-2 分钟

## 性能指标

### 系统性能
- 搜索延迟：< 2 秒（含向量化计算）
- 报告生成：< 1 秒（模板模式）
- 文档上传：< 5 秒/篇（含分块和索引）
- 前端加载时间：< 1 秒

### 数据规模（演示）
- 文档：8 篇研究笔记
- 文档分块：8 个（每篇笔记一个分块）
- 实验记录：30 条
- 研究记忆：6 条
- 向量维度：384
