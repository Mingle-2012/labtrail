# 使用评估

## 评估说明

本文档区分两类数据：

- **实测数据**：在本地开发机上真实调用 API 得到的耗时，可用 `scripts/verify.py` 复现
- **效率估算**：任务耗时对比属于估算，尚未进行真实用户测试，不作为已完成的实验结论

测试环境：macOS（Apple Silicon），Python 3.12，pyseekdb 嵌入式模式，PowerContext Server 本地运行，`all-MiniLM-L6-v2` 在 CPU 上运行。

## 实测性能

以下为 2026-10-29 在本机对 `demo_project` 连续请求的实测耗时（curl `time_total`，多次取值）：

| 操作 | 实测耗时 | 说明 |
| --- | --- | --- |
| 混合检索（5 条结果） | 约 82–119 ms（预热后） | 进程启动后首次请求约 3.9 s，包含 ONNX 向量模型冷启动 |
| 向量检索（5 条结果） | 约 77 ms | IVF 余弦检索 |
| 全文检索（3 条结果） | 约 2–7 ms | FULLTEXT 索引 |
| 实验分析 | 约 2–3 ms | 30 条记录聚合 |
| 记忆列表 | 约 22–37 ms | PowerContext HTTP 调用 |
| 上下文恢复 | 约 21–25 ms | PowerContext HTTP 调用 |
| 周报生成（模板模式） | 约 24–35 ms | 4439 字符 |

`evidence/verification.log` 中的端到端检查耗时（含 HTTP 往返与断言）与上表同一量级：向量检索 80 ms、全文检索 4 ms、报告生成 27 ms、记忆写入 91 ms。

## 效率对比（估算，未做真实用户测试）

### 任务 1：在论文中查找特定结论

**手动方式**：打开 PDF → Ctrl+F 搜索 → 阅读上下文 → 核对出处，估算每篇 5–15 分钟。

**LabTrail 方式**：输入自然语言问题 → 查看带文件名/页码的结果 → 打开原文，估算 30 秒–2 分钟。

### 任务 2：对比算法性能

**手动方式**：打开 CSV → 按方法与数据集过滤 → 手算统计 → 做图，估算 30–60 分钟。

**LabTrail 方式**：打开实验分析页 → 查看聚合统计与图表 → 切换方法过滤，估算 1–2 分钟。

### 任务 3：撰写科研周报

**手动方式**：回顾笔记 → 汇总实验 → 整理结论 → 排版，估算 1–2 小时。

**LabTrail 方式**：点击生成周报 → 审阅并导出 Markdown，模板模式实测生成耗时约 61 ms，人工审阅时间另计。

以上“手动方式”耗时来自日常科研经验的粗略估计，**不是对照实验结果**。
