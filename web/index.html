技术实现

两个数据系统，各司其职

文档与实验走 seekdb，科研记忆走 PowerContext；后端通过 SDK / HTTP API 真实读写，不做“概念引用”。

React 前端 React 19 · TypeScript · Vite · Tailwind CSS · Recharts
→
FastAPI 后端 Python 3.12 · pyseekdb ONNX（本地 CPU，384 维）
→
seekdb + PowerContext seekdb：文档/实验索引；PowerContext：长期记忆与 scope

seekdb 1.4.0（嵌入式）

  • 文档集合：IVF 向量索引（cosine，384 维）+ FULLTEXT 全文索引
  • 混合检索调用原生 hybrid_search，RRF 参数 rank_constant=60
  • 实验 CSV 由 pandas 解析并持久化为 JSON；文档检索通过 metadata 过滤隔离项目
  • 嵌入模型 all-MiniLM-L6-v2 本地运行，不依赖外部 Embedding API

PowerContext 1.4.1（Server 模式）

  • 后端通过 HTTP 调用 /v1/memory/remember、/v1/memory/search、/v1/memory/entries/list
  • 每个 LabTrail 项目对应一个 scope（标题 LabTrail · <project_id>）
  • kind 保存记忆类型；生命周期接口将记忆置为 forgotten
  • 数据持久化在独立数据目录，重启后仍可检索（验证脚本实测）
为什么记忆不放在 seekdb？ 文档检索需要向量与全文索引，而科研记忆需要独立的 scope、类型、状态版本与可遗忘生命周期。 LabTrail 将两者拆分：seekdb 负责“资料与实验”，PowerContext 负责“研究过程中形成的结论与决策”， 避免把长期记忆简化成普通文档块。查看架构说明 →

评委运行指南

          
两种方式，把完整系统跑起来

          
推荐 Docker 一键启动；也可以按本地开发步骤分进程运行。详细排障见部署文档。

        

        

          

            
Docker Compose（推荐）

            
一条命令启动 PowerContext、后端与前端；首次构建会把嵌入模型打进镜像，之后可离线运行。

            

              
              
git clone https://github.com/Mingle-2012/labtrail.git
cd labtrail
docker compose up --build

            

            
启动后访问：前端 http://localhost:5173 · API 文档 http://localhost:8000/docs。首次构建约 10–20 分钟，需联网下载依赖与模型。

            

              Docker 24+Compose v2端口 5173 / 8000
            

          

          

            
本地开发（分进程）

            
需要 Python 3.12、Node.js 20+；PowerContext 以 --role all 启动。

            

              
              
python3.12 -m venv venv && source venv/bin/activate
pip install -r backend/requirements.txt
cp .env.example .env
powercontext server run --host 127.0.0.1 --port 8890 --role all &
python scripts/load_demo_data.py
cd backend && PYTHONPATH=. uvicorn app.main:app --port 8000
cd frontend && npm ci && npm run dev -- --port 5173

            

            
首次运行会下载 all-MiniLM-L6-v2（约 90 MB）。完整步骤、环境变量与常见问题见
              部署文档。
            

            

              Python 3.12Node 20+PowerContext 1.4.1seekdb 1.4.0
            

          

        


        

          

            
本站（Qoder Sites 静态版）

            
公网可直接访问、无需登录；提供真实数据快照与交互演示；不运行 Python 后端，因此没有 /api/*。适合快速了解产品与查看证据。

          

          

            
本地 / Docker 完整版

            
包含完整 REST API、文件上传、现场检索、记忆写入与周报生成；可运行 scripts/verify.py 复现全部检查，并在 /docs 查看 OpenAPI。
